# Panduan PIMPINAN

PIMPINAN fokus pada pengawasan tingkat lembaga: pantau kondisi, putuskan pengajuan, dan baca laporan. Menu operasional unit (kasir, stok, layanan) tidak tampil agar fokus.

## 1. Dashboard Eksekutif

Tampilan utama berisi grid jalan pintas (Input Data, Buku Kas, Papan Pantau, Laporan, Pengumuman, Persetujuan, Unit, Kategori, Pegawai, Belanja), kartu **Menunggu Persetujuan** (jumlah pengajuan menunggu keputusan), dan ringkasan **Total Saldo**.

![Dashboard Pimpinan](screenshots/06-pimpinan-dashboard.png)

## 2. Menyetujui Pengajuan (`Keuangan Lembaga → Pengajuan`)

1. Buka `Keuangan Lembaga → Pengajuan`.
2. Klik pengajuan untuk melihat rincian (nominal, keperluan, pengaju, unit).
3. Pilih **Setujui** atau **Tolak** (sertakan alasan bila menolak).

![Daftar pengajuan](screenshots/07-pimpinan-approvals.png)

> Pengajuan yang disetujui/ditolak tercatat otomatis (siapa + kapan) sebagai jejak audit.

## 3. Laporan (`Keuangan Lembaga → Laporan`)

Rekap pemasukan, pengeluaran, dan saldo per unit / per periode. Gunakan untuk evaluasi mingguan/bulanan.

![Laporan](screenshots/08-pimpinan-reports.png)

## 4. Buku Kas (`Keuangan Lembaga → Buku Kas`)

Melihat seluruh transaksi yang tercatat di semua unit. Bisa disaring per unit, kategori, dan tanggal.

![Buku kas](screenshots/09-pimpinan-buku-kas.png)

## 5. Menu Lain

- **Papan Pantau** — pantauan live aktivitas unit.
- **Pengumuman** — sampaikan informasi ke seluruh pengguna.
- **Kelola → Unit** — melihat daftar unit (baca).
- **Kelola → Kategori Keuangan** — mengatur kategori pemasukan/pengeluaran.
- **Kepegawaian → Pegawai** — melihat daftar pegawai/pengguna.

## Tips

- Cek badge angka di menu **Pengajuan** setiap hari agar tidak ada pengajuan menumpuk.
- Keputusan (setuju/tolak) sebaiknya diiringi alasan tertulis bila menolak.
